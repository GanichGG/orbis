# stick2r6 v2 — стикмены с видео → R6-анимация (нейросеть StickPose)

## Установка
```
pip install opencv-python numpy scipy scikit-image pillow torch
```
Для видеокарты (RTX) поставьте torch с CUDA с pytorch.org. Программа сама использует GPU, если он есть.

## 1. Разметка видео
```
python app/stick2r6.py видео.mp4 --facing r,l
```
Опции: `--start/--end` (кусок видео, кадры), `--first 6` (сколько разных поз спросить сначала),
`--view front` (видео снято спереди), `--fresh` (начать заново).

1. **Пипетка.** Кликните по каждому персонажу, при необходимости несколько раз по разным оттенкам.
   N переключает на следующего персонажа, A/D листают кадры, чтобы проверить заливку; Enter — готово.
2. **Вопросы.** Сначала несколько кадров с разными позами, потом только спорные.
   Точки уже расставлены догадкой сети: перетащите неверные и нажмите Enter.
   Q/W меняют местами руки/ноги, Backspace — «не видно», S — пропустить кадр, Esc — хватит вопросов.
   Каждые несколько ответов сеть дообучается на них под это видео.
3. **Проверка.** Пробел — воспроизведение, E — поправить кадр, Enter — экспорт в `видео.r6.json`.

Ваши разметки также сохраняются в `weights/real/*.npz`: это датасет для дообучения модели.

## 2. Импорт в Blender (5.x)
**Твой IK-риг:** `blender/blender_import_ikrig.py` (MasterControl, LowerTorso-FK, IK ног, FK рук/головы; `LEG_MODE` = plant/straight).
**Простой R6-скелет:**
Scripting → Open → `blender/blender_import_r6.py` → Run Script, затем выберите `.r6.json` в окне.
Если выделен ваш R6-риг (Torso, Head, Left/Right Arm, Left/Right Leg), анимация ляжет на него,
иначе создастся новый. Ошибки показываются в строке состояния, подробности — в системной консоли.

## 3. Обучение модели (stickpose/)
```
cd stickpose
python train.py --resume ../weights/stickpose.pt --steps 20000 --out ../weights/stickpose.pt
python train.py --width 32 --steps 60000 --out ../weights/stickpose_w32.pt    # модель крупнее (видеокарта)
python train.py --resume ../weights/stickpose.pt --real ../weights/real --steps 5000   # + ваши разметки
python evaluate.py ../weights/stickpose.pt     # точность на синтетике
python overlay.py ../weights/stickpose.pt видео.mp4 out "x,y;x,y"   # наложение без разметки
```
- `synth.py` — генератор стикменов в стиле Stick Nodes. Сюда добавляются новые стили.
- `model.py` — U-Net: силуэт (свой + чужие) → карты голова/шея/таз/кисти/стопы.
- `track2.py` — трекинг по всему видео (Витерби 2-го порядка, лево/право, смена плана, память поз).
- `colorseg.py` — пипетка: цвет персонажа против палитры фона в каждом кадре.

Ограничения: персонаж должен заметно отличаться цветом от фона. Одинаковые по цвету персонажи
делятся по положению, поэтому при плотном контакте программа спрашивает чаще. Крупные планы
без стикменов и сплошные эффекты пропускайте (S или `--start/--end`).
